# 准确率 vs 精确率

准确率（Accuracy）和精确率（Precision）是两个容易混淆但本质不同的评估指标。

---

## 📊 准确率 (Accuracy)

### 定义
完全正确的样本占总样本的比例

### 公式
```
Accuracy = (TP + TN) / (TP + FP + FN + TN)
         = 正确预测数 / 总样本数
```

### 关注点
整体对错（"总共对了多少？"）

### 示例
```python
总样本数 = 10
正确预测 = 7 (TP=2, TN=5)
错误预测 = 3 (FP=2, FN=1)

Accuracy = 7/10 = 0.7 (70%)
```

### 特点
- ✓ 简单直观
- ✓ 适合平衡数据集
- ✗ 在不平衡数据集上会失真

### 不平衡数据集的问题
```
场景：100个样本，5个正例，95个负例

模型A：全部预测为负例
  正确 = 95 (所有负例)
  Accuracy = 95/100 = 0.95  ← 看起来很高，但没用
  
模型B：预测了10个正例，5个对
  Accuracy = (5+90)/100 = 0.95  ← 实际更有用
```

## 🎯 精确率 (Precision)

### 定义
模型预测为正确的样本中，真正正确的比例

### 公式
```
Precision = TP / (TP + FP)
          = 真正确 / 模型预测为正的总数
```

### 关注点
预测的质量（"我预测的有多准？"）

### 示例
```python
模型预测了5个函数: [func_a, func_b, func_c, func_d, func_e]
实际需要的函数: [func_a, func_b, func_d]

预测对的 (TP): func_a, func_b, func_d → 3个
预测错的 (FP): func_c, func_e → 2个

Precision = 3 / (3+2) = 3/5 = 0.6 (60%)
```

### 含义
我预测的5个函数中，只有60%是对的

### 适用场景
关注误报率（如垃圾邮件检测、推荐系统）

---

## 🔄 核心区别

| 维度 | 准确率 (Accuracy) | 精确率 (Precision) |
|------|------------------|-------------------|
| **关注点** | 整体对错 | 预测的质量 |
| **问题** | "总共对了多少？" | "我说对的有多少真对？" |
| **分母** | 总样本数 | 模型预测为正的数量 |
| **适用场景** | 平衡数据集 | 不平衡数据集 |
| **公式** | (TP+TN) / 全部 | TP / (TP+FP) |

---

## 💡 形象比喻

### 准确率
```
考试：100道题，做对70道
准确率 = 70/100 = 70%
→ 看整体表现
```

### 精确率
```
考试：只做了10道题，对了7道，其他90道没做
精确率 = 7/10 = 70%
→ 只看做了的题有多少对
```

## 📝 实际应用对比

### 场景：垃圾邮件检测

**模型A（高准确率，低精确率）：**
```
总邮件：1000封（900正常，100垃圾）
预测为垃圾：500封
  - 真垃圾：100封 (TP)
  - 误判：400封 (FP)

Accuracy = (100+500)/1000 = 0.6
Precision = 100/500 = 0.2  ← 误报太多！
```

**模型B（高精确率）：**
```
预测为垃圾：120封
  - 真垃圾：100封 (TP)
  - 误判：20封 (FP)

Accuracy = (100+880)/1000 = 0.98
Precision = 100/120 = 0.83  ← 误报少
```

## 🎯 何时使用

### 使用准确率
- 数据集平衡（正负例数量相近）
- 关注整体表现
- 所有类别同等重要

### 使用精确率
- 数据集不平衡
- 误报代价高（如医疗诊断）
- 需要保证预测质量
